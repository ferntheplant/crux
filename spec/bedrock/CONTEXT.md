# Bedrock words

The words that only bedrock uses. They add to the root glossary ([Context](../../CONTEXT.md)), and they never define again a word of it. No message to a tool other than belay uses them.

## Words

**event** — One record of what a run did: a token, a tool call, a tool result, a step, an error, or the completion.

**harness** — The program that runs an agent, for example a coding-agent command line.

**image** — A prepared disk from which bedrock provisions a workspace.

**outcome** — How a run ended: `succeeded`, `failed`, `cancelled`, `stuck`, or `budget spent`.

**provider** — A service that supplies workspaces, for example a host of virtual machines.

**run** — One agent in one workspace, from its start to its completion.

**snapshot** — A saved copy of a workspace, from which bedrock can provision a different workspace.

**workspace** — A machine or a container that holds a checkout, its dependencies, and its local services.
