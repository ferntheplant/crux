# Crux documentation

The [abstract](../ABSTRACT.md) says what crux is in one page. This is the whole of it.

Section numbers are stable and they are the citation form: **§6.6** means the same thing in a
commit message, in a tracker, and in another repository's notes. A section keeps its number when it
moves between these documents, so cite the number and resolve it here.

## The runbooks

Procedure, read per session. They carry no history and no rejected alternatives — the reasoning
stays in the sections they link to.

| Read                               | When                                                        |
| ---------------------------------- | ----------------------------------------------------------- |
| [Builder](./runbooks/builder.md)   | you were handed an amendment and are making its claims true |
| [Reviewer](./runbooks/reviewer.md) | you did not build it, and you are producing the readout     |
